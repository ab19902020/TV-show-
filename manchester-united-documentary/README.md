# Manchester United animated documentary parody

This folder holds the reusable source assets for the new animated series. Keep
future backgrounds, characters, audio and scene files within this folder rather
than mixing them into the existing Roy Keane scene.

All nine sheets are 1536 × 1024 RGBA PNGs with real alpha transparency. Outfit
order is home, training, match kit for the players and home, training, suit for
Carrick. The art uses the same inked caricature treatment with no prominent
drawn joint discs. These are **source sheets**, not a finished rig: cut the
individual pieces, set concealed pivots, and test viseme placement and motion
in a scene before treating them as animation-ready. The kit details are
illustrative artwork and should be checked against any exact season reference.
