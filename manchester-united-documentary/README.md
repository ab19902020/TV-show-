# Manchester United animated documentary parody

This folder holds the reusable source assets for the new animated series. Keep
future backgrounds, characters, audio and scene files within this folder rather
than mixing them into the existing Roy Keane scene.

## Backgrounds

[BACKGROUNDS.md](BACKGROUNDS.md) lists the background and canvas images in [`assets/backgrounds/`](assets/backgrounds/), which are grouped by location: training ground, boardroom, manager's office, tactics room, locker room, stadium exterior, tunnel, mixed zone, press conference and TV studio.

## Characters

**[CHARACTERS.md](CHARACTERS.md) is the character section.** It has the house-style guide, the status of every cast member and links to each sheet.

Every character folder in [`assets/characters/`](assets/characters/) is laid out the same way:

- `outfits.png`, `face-visemes.png` and `movement.png` are the primary house-style sheets.
- `house-style/` holds extra sheets in the same bold inked caricature style.
- `other-styles/` holds off-style art, kept for likeness and kit reference only. It needs redrawing before it goes on screen.

The approved style is the Matheus Cunha / Bruno Fernandes / Michael Carrick look. The sheets are 1536 × 1024 PNGs, and the original three characters' sheets use real alpha transparency. These are **source sheets**, not a finished rig: cut the individual pieces, set concealed pivots, and test viseme placement and motion in a scene before treating them as animation-ready. The kit details are illustrative and should be checked against an exact season reference.
