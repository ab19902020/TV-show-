# Anonymous Feedback: Clony AI voiceovers

One clip per line, 18 in total (Brent B01–B08, Gareth G01–G05, Tim T01–T05). Each `.txt` file next to this one holds just the text to paste into Clony AI. The words in square brackets are expression tags: Clony uses them to set the delivery and does not say them.

**When you record:**

- Make each ID its own clip, and name the download after its ID (for example `B03.mp3`) so it lands on the right shot.
- Use dry, conversational takes with no music or reverb. Don't add long pauses: the edit puts in the awkward silences.
- The brief's `.....` breath markers are gone, so Clony won't read them out. Sentence breaks give the natural breaths.
- If a tag gets read aloud or does nothing on your voice model, delete it and keep the words. If a take comes out too big, use fewer tags. Everything should stay small and believable.
