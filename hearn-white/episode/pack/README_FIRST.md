# Hearn v White — animation production pack

Start with script/DIRECTORS_SCRIPT.md. This is original fictional satire, not a real event announcement.

Assets are generated in the user's established bold caricature style using the supplied Overcrap image as style reference. Characters use only a closed slit mouth; Claude supplies lip sync. Read the actual image inventory before building; a requested pose list is not proof an asset exists.

Use PNG sheets as illustration sources. They require extraction and rigging; do not treat independently drawn poses as mathematically registered walk frames. Use original high-resolution sheets. Keep alpha edges, consistent head/body scale and a stable ground line. Do not bake a background into characters.

Build landscape with portrait-safe action. Sound and final voice timings determine final shot length. Use existing animation engine, Whisper alignment, articulated limbs, anchored props and subtle camera motion. Preview 720p first; final 4K after approval. No Runway.

Deliver renderable project, used assets, dialogue timings, scene graph and README together. Every shot needs an assigned background, cast rig, camera and audio cue. If extra in-between frames or puppet pieces are required, generate/draw them in the same style rather than stretch a bad pose.
