# United Road: The Glazers' Cash Machine

A 9:16 portrait narration film (1080x1920, about 5 minutes) on how the Glazer ownership has paid the family while
the club carried the cost. One narrator, the show's existing cutouts, a satirical money machine inside Old Trafford.

| File | What it is |
|---|---|
| [`brief.md`](brief.md) | The production brief: narration, portrait direction, shot table, claim check and sources. |
| [`Clony_Narration.md`](Clony_Narration.md) | **What to record**: the nine narration chunks with Clony AI expression tags, each under 1,000 characters. |
| `Clony_Narration/01.txt` ... `09.txt` | The same chunks, one file each, to paste straight into Clony. |
| `clony_narration.py` | Rebuilds the two above and checks every chunk stays under 1,000 characters. |

**Status:** the narration is ready to record. Send the nine clips (any order, one per chunk) and the film is built
from them: the cash machine, the 2005 takeover papers, the receipt, the dividend tray, the share certificates, the
voting tokens and the running meter, with the Glazer, Ratcliffe and supporter cutouts.
